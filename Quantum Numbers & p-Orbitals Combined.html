📚 Code Explained for Learners

File Structure: This single HTML file contains all the logic. It uses style for design and script for interactivity.

Key Libraries:

  • html2canvas: Converts the DOM element (infographic) into an image pixel-by-pixel for downloading.
  • Three.js: Creates a 3D scene (canvas) where we draw geometric shapes (dumbbells) using 3D coordinates.

Interactive Concepts:

  • State Management: We use JavaScript variables to track scores, electron counts, and visibility toggles.
  • Event Listeners: Buttons trigger functions (e.g., checkMatrixAnswers()) that update the DOM.
  • Local Storage: The flashcard system saves your progress in your browser so you don't lose it on refresh.
